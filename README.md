# 🏋️ Fitness Tracker

A responsive, browser-based Fitness Tracker built with **HTML, CSS, and Vanilla JavaScript**. The application helps users track workouts, water intake, weight, steps, goals, personal records, and fitness progress while providing an interactive exercise library with tutorial videos.

The project uses **IndexedDB for persistent local data storage** and integrates modern **Browser APIs and public APIs** to provide features such as workout timers, notifications, geolocation, offline support, Web Workers, Fetch API, and YouTube exercise tutorials.

## ✨ Features

* 📊 Dynamic fitness dashboard
* 🏃 Workout tracking with CRUD operations
* ⏱️ Workout timer
* 📚 Exercise library with search and filters
* 🎥 YouTube exercise tutorial integration
* 💧 Water intake tracking
* ⚖️ Weight tracking and progress
* 👟 Step tracking
* 🎯 Fitness goals and progress
* 🔥 Workout streak tracking
* 🏆 Personal records
* 📈 Progress charts and analytics
* 🧮 BMI and calorie estimation
* 🔐 Simple local user profile/login
* 🗄️ IndexedDB-based persistent storage
* 📍 Geolocation API
* 🔔 Notifications API
* 🌐 Online/offline detection
* ⚙️ Web Workers for calculations
* 🔊 Web Audio API
* 📡 Fetch API and asynchronous JavaScript
* 📥 Import/export fitness data
* 📱 Fully responsive design for desktop, tablet, and mobile

## 🛠️ Technologies

## 🎯 Project Goal

The goal of this project is to build a practical fitness application while exploring **Vanilla JavaScript, DOM manipulation, asynchronous programming, browser storage, APIs, and modern browser capabilities** without relying on frontend frameworks or a backend.
