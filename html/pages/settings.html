Backup & Restore

Fitness data for this profile is stored in IndexedDB on this device. Export a JSON snapshot for backups, or import previously saved records.

Web APIs Demonstrated:
  • Blob API: Generates downloadable JSON file directly in memory
  • URL.createObjectURL(): Creates temporary download link
  • FileReader API: Asynchronously parses uploaded JSON file

Danger Zone

Reset All Data

Permanently wipes all logged workouts, steps, water, weight history, and custom goals from this device. Requires confirmation.
